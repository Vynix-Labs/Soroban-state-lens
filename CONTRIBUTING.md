# Contributing to Soroban State Lens

Thanks for helping improve Soroban State Lens. Small, focused pull requests are
welcome.

## Prerequisites

- Node.js 20 or newer
- Bun 1.0 or newer


Run `bun run check:env` to verify the Node.js and Bun versions.

## Set up locally

```bash
git clone [https://github.com/Vynix-Labs/Soroban-state-lens.git](https://github.com/Vynix-Labs/Soroban-state-lens.git)
cd Soroban-state-lens
bun install
